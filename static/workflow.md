# Library Management Project


## Demo Instructions

*   The admin user has additional privileges to manage books, users, and issues.
*   The user interface is designed to be intuitive and easy to use.
### Demo Credentials

The application includes demo credentials:

*   **Admin User:** `admin@g.com` / `ad`
*   **Regular User:** `w` / `w`

### 1. Sign Up (If you don't have an account)

*   Click on the "Sign Up" link.
*   Enter an email and password.
*   Click "Sign Up".
*   **Important:** A new user account needs to be activated by an administrator before you can log in. You can use the demo credentials provided on the login page, to activate.

### 2. Login

*   Click on the "Login" link.
*   Enter your registered email and password.
*   Click "Login".
*   You will be redirected to the home page.

### 3. Browse Books

*   Click on the "Books" link in the navigation bar.
*   You will see a list of available books.
*   You can use the search bar to find specific books by ID, title, author, or section.

### 4. Request a Book

*   As a regular user, you can request a book by clicking the "Request" button next to the book you want.
*   A message will confirm that your request has been submitted.

### 5. Interact with the Application

*   Explore the different sections and functionalities available to you based on your user role.
